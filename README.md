# GillisT Enterprises

GillisT.com is the public website for Thomas A. Gillis's independent applied AI and strategic advisory work.

## Development

An Astro static site. Use `npm ci` and `npm run build`. The public entrypoint is `src/pages/index.astro`; its stylesheet is `public/assets/styles.css`. GitHub Pages deploys the `dist` output when `main` changes.

The homepage presents applied AI development and evaluation, technical proposal and program review, technology-partnership advisory, the Tekwill experience, professional background, two publications, and email-based project inquiries. `/anchor/` retains the existing private mindfulness exercise. Older about, credentials, labs, and research routes retain their redirects to the homepage.

## Content notes

Public copy uses the owner's professional account and supplied resumes. It describes substantial concept-note development without claiming sole authorship. It intentionally omits unresolved Tekwill opening dates and funding multipliers. ATIC and Tekwill links establish the project context, not individual attribution. No health information, unverified client endorsements, prices, or guaranteed availability are published.

A standalone homepage review copy is included at `review/gillist-preview.html`. Its CSS and favicon are embedded; the original web fonts require an internet connection. The quiet-pause link opens the existing live page.
